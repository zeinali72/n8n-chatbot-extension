🚀 How to Install & Test:

1. Open Chrome Extensions Page

Navigate to chrome://extensions/ in your Chrome browser

2. Enable Developer Mode

Toggle the "Developer mode" switch in the top-right corner

3. Load Unpacked Extension

Click "Load unpacked" and select the dist folder from this project

4. Configure Settings

Click on the extension icon in Chrome toolbar, then go to "Options" to set up your OpenRouter API key

5. Test the Extension

Visit any website to see the floating chat button in the bottom-right corner

⚙️ Required Setup:

OpenRouter API Key: Get your free API key from OpenRouter.ai

You'll need this to configure the AI model in the extension settings.
